RoboDataHub is an end-to-end egocentric robotics data pipeline that transforms raw first-person video into structured, machine-readable datasets for robotic learning. The system processes egocentric video streams, segments human actions with temporal boundaries, detects hand-object interactions, and generates structured annotations that can be directly used to train intelligent systems. Addressing the lack of real-world, region-specific datasets—especially compared to existing resources like Ego4D and EPIC-KITCHENS—RoboDataHub focuses on scalable data generation tailored to real-world environments, particularly in India. Built using Python, OpenCV, MediaPipe, and YOLOv8, the pipeline bridges the gap between computer vision, human activity understanding, and robotic execution, enabling the creation of high-quality datasets for robotics, humanoid AI, and autonomous systems.
