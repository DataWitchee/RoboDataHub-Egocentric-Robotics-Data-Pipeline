RoboDataHub is an end-to-end egocentric robotics data pipeline that transforms raw first-person video into structured, machine-readable datasets for robotic learning. The system processes egocentric video streams, segments human actions with temporal boundaries, detects hand-object interactions, and generates structured annotations that can directly train intelligent systems. Addressing the lack of real-world, region-specific datasets—especially compared to existing resources like Ego4D and EPIC-KITCHENS—RoboDataHub focuses on scalable data generation tailored to real-world environments, particularly in India. Built using Python, OpenCV, MediaPipe, and YOLOv8, the pipeline bridges computer vision, human activity understanding, and robotic execution. The output is provided in structured formats such as JSON and CSV, where CSV files follow a schema like: `video_id, start_time, end_time, action, object, interaction, description`, enabling easy integration into machine learning pipelines and robotic training systems.
